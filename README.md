# Claude AI Chat App

A modern AI chatbot built using React, Node.js, and Anthropic Claude API.

## Features

* Real-time AI chat
* Claude API integration
* Multiple chat conversations
* Sidebar chat history
* Markdown rendering
* Local chat persistence
* Modern responsive UI
* Auto-scroll functionality
* Loading states

---

## Tech Stack

### Frontend

* React
* Tailwind CSS
* React Markdown

### Backend

* Node.js
* Express.js
* Anthropic SDK

---

## Project Architecture

Frontend → Backend → Claude API

```text
React App
   ↓
Express Server
   ↓
Anthropic Claude API
```

---

## Installation

### Frontend

```bash
npm install
npm start
```

### Backend

```bash
npm install
node server.js
```

---

## Environment Variables

Create `.env` file inside backend:

```env
ANTHROPIC_API_KEY=your_api_key
```
